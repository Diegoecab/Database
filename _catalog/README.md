# Script Catalog

This directory contains repository-level metadata generated by:

```bash
python3 tools/db_repo_manager.py catalog
```

`scripts_catalog.json` is the global machine-readable script index intended for
search, MCP resources and skill discovery. Each row includes engine, path,
category, description, risk, parameters, hash, header status and secret-flag
status.

Per-engine catalogs live under `<engine>/_catalog/` and include:

- `inventory.csv`: all files for that engine.
- `scripts_catalog.json`: script-only index for that engine.
- `cleanup_candidates.csv`: generated outputs, unsafe names and non-config exact
  duplicate candidates.
- `validation_report.json`: validation summary.
